This repository contains `R` code to reproduce the results in the paper

> S. Allen, J. Burnello, and J. Ziegel (2025). 
> Assessing the conditional calibration of interval forecasts using decompositions of the interval score.
> ArXiv preprint [arXiv:2508.18034](https://arxiv.org/abs/2508.18034).

The methods developed in this paper are available in the more general `CondIntCal` package at https://github.com/sallen12/CondIntCal.

## Conditional calibration of interval forecasts

The above paper concerns calibration of forecasts in the form of central prediction intervals. The calibration of interval forecasts is typically assessed by checking whether the outcome falls within the interval with the nominal coverage probability. However, this is typically assessed unconditionally, neglecting conditional biases that may be present in the forecast. This work introduces a conditional decomposition of the interval score that provides a measure of conditional calibration of interval forecasts. This measure quantifies the amount by which the interval score would be improved if the forecast were conditionally calibrated.

## Instructions

### Simulation Study

The simulation study results can be obtained by sourcing the `main.R` file in the `Sim_Study` folder. The `utility_funcs.R` file in this folder is sourced by the `main.R` file. Running this code saves Figure 1 in the `Figures/` directory, and prints the values for Table 1. This runs in roughly 90 seconds. 

### Case Study

#### Code

The case study results can be obtained by sourcing the `main.R` file in the `Case_Study/` folder. Before running `main.R`, the variable `var` on line 14 should be changed to one of `"star"`, `"bike"`, or `"facebook_1"` depending on what application results are desired for:
- `var <- "star"` reproduces the results in the first panels of Table 2 and Figure 2. This runs in roughly 20 seconds.
- `var <- "bike"` reproduces the results in the first panels of Table 2 and Figure 2. This runs in roughly 7.5 mins.
- `var <- "facebook_1"` reproduces the results in the first panels of Table 2 and Figure 2. This runs in roughly 1 hour.
  
Running `main.R` saves the relevant panel of Figure 2 in the `Figures/` directory, and prints the values for the relevant panel of Table 2.

#### Data

The `Case_Study/data/` repository contains the forecast and observation data that is loaded when running `Case_Study/main.R` to generate the results. The data is divided into three subfolders `star`, `bike`, and `facebook_1`, corresponding to the three applications in the case study. Each subfolder contains eight `.csv` files, each containing the interval forecasts generated from one of the eight forecasting methods analysed in the case study. For example, the `Case_Study/data/bike/bike_Ridge_int0.csv` file contains the lower and upper bounds of the interval forecasts generated by Ridge Regression, as well as the corresponding observations.

These interval forecasts were generated from code and data available at https://github.com/yromano/cqr. This requires the `bike_train.csv` and `STAR.csv` files in the `datasets/` folder of the `cqr` repository, as well as the `Features_Variant_1.csv` file that can be downloaded from https://archive.ics.uci.edu/dataset/363/facebook+comment+volume+dataset (see also the `datasets/facebook/` folder of the `cqr` repository). The `reproducible_experiments/all_cqr_experiments.py` file in this `cqr` repository was run with `test_methods = ['linear', 'neural_net', 'random_forest', 'quantile_net', 'cqr_quantile_net']`, `dataset_names = ['star', 'facebook_1', 'bike']`, and `random_state_train_test = [0]`. Code is added to the `reproducible_experiments/run_cqr_experiment.py` file to save the generated interval forecasts. For example, the following code is added to line 229 of this file to save the interval forecasts obtained from the Ridge Regression model:
```
int_df = pd.DataFrame({'Lower': y_lower, 'Upper': y_upper, 'Obs': y_test})
int_df.to_csv('Case_Study/data/dataset_name/' + dataset_name + '_Ridge_int' + str(random_state_train_test) + '.csv', index=False)
```
Analogous code is added to save the interval forecasts for the other models. For each of the eight models, this saves one `.csv` file containing the interval forecasts and observations in the relevant `Case_Study/data/star/`, `Case_Study/data/bike/`, `Case_Study/data/facebook_1/` subfolders. These files are then used to generate the results in the paper.
